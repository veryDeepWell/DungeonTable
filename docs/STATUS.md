# Функциональная версия 0.2 — покрытие ТЗ

22 ноября 2026. Это проверяемая основа, а не заявление о выполнении всех пунктов ТЗ. Внешний вид намеренно простой.

| Раздел | Реализовано | Граница / осталось |
|---|---|---|
| Статический клиент | index.html в корне, относительные модули, тёмная тема, без сборки и npm-зависимостей | Реальное размещение Pages не выполнялось |
| Стол | Токены, выделение, перемещение, привязка, масштаб к курсору, камера, линейка, пинг | Нет группового выделения, путевых точек, поиска пути, трудной местности и столкновений |
| Сцены | Создание, настройка сетки/масштаба, отдельная подготовка и публикация, постоянные листы | Переносить токены на новую сцену нужно через «На сцену»; нет точек входа и полноценных миниатюр |
| Карта | Загрузка PNG/JPEG/WebP, разбиение на фрагменты, раскрытие, закрытая графика не отправляется игрокам | Нет стен, динамического света и личного поля зрения; раскрытие только квадратными фрагментами |
| Объекты | Картинки, круг/конус/линия/прямоугольник, перемещение, размер, поворот, скрытие, удаление | Нет сложного редактора обрезки и проверки попадания цели в область |
| Лист | Все 6 характеристик, 18 навыков, владения/экспертиза, HP/временные HP, КД, скорости, заметки, портрет | Ручная форма вместо пошагового помощника |
| Владение | Назначение игрока ГМ, независимость от стороны, серверная проверка команд | Совладелец одного героя и наблюдатель как отдельная роль пока не поддерживаются |
| Предметы | Редактор, картинки, шаблоны/экземпляры, количество, вес, надевание брони и оружия | Нет полного справочника, валют, автоматического лимита веса, настройки зарядов и неопознанных свойств |
| Инвентарь | Частичное выкладывание стопок, подбор, контейнеры, открытие ГМ, передача с согласием, зелья | Нет объединения совместимых стопок и произвольного глубокого дерева в UI; дистанцию подбора определяет ГМ |
| Броски | d4–d100 и ограниченные формулы, источник модификаторов, d20-проверки, навыки и спасброски | Нет парсера сложных выражений; большие формулы ограничены |
| Автоматические проверки | Инициатива, атака/урон, спасбросок способности, концентрация, смерть при начале хода | Сюжетную проверку назначает ГМ; автоматические реакции и вся система состояний отсутствуют |
| Эффекты | Плоский бонус, дополнительная кость, преимущество/помеха, область применения, источник, концентрация, срок по началу/концу хода | Правила повторяющихся/несовместимых эффектов и концентрация группы целей одного заклинания требуют доработки; реальные игровые минуты отмечаются вручную |
| Бой | Выбор участников/сторон до инициативы, очередь, раунды, смена стороны без переброса, ручной порядок | Три стороны относительно партии; нет матрицы отношений произвольных фракций |
| Бюджет | Действие, бонусное действие, реакция, перемещение; урон оружия с подтверждением либо сразу | Дополнительные атаки и реакции — ручной бюджет ГМ; скрытая очередь в UI игрока может означать «ход скрытого участника» |
| Урон | Критические кости, сопротивление/иммунитет/уязвимость, временные HP, концентрация и нулевые HP | Нет всех особых случаев, автоматических реакций и эффектов конкретных классов |
| Заклинания | Настраиваемая формула, цель, расход ячейки, спасбросок, половина урона/лечение | Нет каталога, кастинга по книге, подготовки заклинаний и всех компонентов; применение напрямую после подтверждения формы |
| Развитие | Уровень, HP, характеристика, заметка способности, пересчёт владения | Не выбирает подкласс/черту/заклинания; ячейки правятся вручную, нет мультикласса |
| Отдых | Короткий с костями хитов, восстановление указанных ресурсов, долгий для HP/костей/ресурсов/ячеек | Условия отдыха, особенности классов и длительность подтверждает ГМ |
| Сеть | HTTP API, комнаты, пароли scrypt, личные ключи, роли, последовательный опрос с 700 мс паузой | Нет push-транспорта и автоматического переноса хоста |
| Повторы | Уникальные ID команд, возврат уже принятого результата после перезапуска, кнопка повтора при потере ответа | Неотправленный запрос не хранится после закрытия вкладки; потерявшему ответ нужно переподключиться и сверить состояние, прежде чем повторять действие новой командой |
| Приватность | Серверные проекции, закрытые NPC/заметки/контейнеры/история, авторизованные изображения | Не является криптографической защитой от владельца сервера; раскрытые раньше данные нельзя «забыть» у получателя |
| Cloudflare | Самостоятельный Worker/DO, аренда 45 с, запускатель Node+Tunnel, продление 12 с | Не развёрнуто в аккаунте, внешние сети/лимиты не испытаны |
| Сохранение | IndexedDB локально, SQLite на сервере, транзакции, восстановление комнат и ключей | Ресурсы внутри JSON состояния SQLite; нет отдельного файлового каталога и автоматических резервных копий |
| Экспорт | JSON с встроенными изображениями, валидация, импорт после подтверждения | ZIP и полноценные миграции между версиями схемы не реализованы |
| Журнал / чат | Расчёты, закрытые/публичные записи, автор и время, чат, аудит отмены | Не более 1000 записей в текущем состоянии; нет архивной бесконечной истории |
| Отключение | Статус через 30 с, без технического поражения/смерти; восстановление адреса через реестр | Нет автоматической паузы при отсутствии ГМ |
| Проверки | Ядро, HTTP-сервер с реальным SQLite, синтетическая отрисовка всех панелей | Браузерный UI и игра с удалёнными людьми не проверены |

## Важные отличия от полного ТЗ

Для проверки возможностей доступны ручные обходные пути. Для заявления о готовом продукте ещё нужны реальная браузерная сессия, внешнее подключение, сверка расширенных правил 2024, автоматические резервные копии и закрытие оставшихся требований. Кнопка «Что работает» не объявляет неподдерживаемые механики реализованными.

Изменения исходного ТЗ этим файлом не отменяются. Он фиксирует текущее покрытие реализации и помогает выбрать следующий этап после пробной игры.
